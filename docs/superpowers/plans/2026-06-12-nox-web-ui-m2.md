# Nox Web UI — M2: Cérebro 3D + Sync de Voz Real — Plano Compacto

**Modo de execução:** inline (sem subagentes), por preferência do usuário.
**Spec:** `docs/superpowers/specs/2026-06-12-nox-web-ui-design.md` §4.3, §5 e marco M2.
**Critério de aceite:** "Falando" pulsa visivelmente com a voz real; 60fps desktop.

## Decisões

- **Forma do cérebro:** procedural (união de elipsoides + córtex amostrado na casca, idêntica ao demo aprovado), sem asset GLB externo — zero risco de licença/download; upgrade para malha anatômica fica como polish (M5+).
- **Nível de voz:** RMS por chunk calculado no backend (função pura em `core/audio_levels.py`), emitido via hook opcional `ui.on_audio_level()` já existente no adapter; throttle de ≤30 eventos/s no adapter.
- **Render:** React Three Fiber (R3F v8, compatível React 18) + bloom de `@react-three/postprocessing`. Nível de voz lido **imperativamente** no frame loop (`store.getState().level`) — sem re-render React a 30Hz.
- **Fallback:** sem WebGL → cai no cérebro canvas 2D do M1 (já no repo).

## Etapas

### A. Backend — níveis de áudio (TDD)

1. `core/audio_levels.py`: `rms_level(pcm: bytes) -> float` — int16 LE mono → RMS normalizado [0,1] com ganho perceptual (`min(1, rms/32768 * 3.2)`); tolera chunk vazio/ímpar.
2. `tests/core/test_audio_levels.py`: silêncio→0; senoide cheia→~1; meia amplitude→~0.5±tol; bytes ímpares não explodem.
3. `main.py` `_play_audio`: após cada chunk TTS, `lvl = rms_level(chunk)` → `getattr(self.ui, "on_audio_level", None)` e chama se existir (legacy NoxUI não tem — no-op).
4. `main.py` `_listen_audio`: no callback do mic, quando não muted/não speaking, emite `rms_level(bytes) * 0.6` (reação sutil ao usuário).
5. `server/web_ui.py` `on_audio_level`: throttle por `time.monotonic()` (mín. 1/30s entre broadcasts; sempre emite se level==0 para "zerar" o cérebro). Teste no `test_web_ui.py`.

### B. Frontend — dependências

`webui/package.json` (dev e runtime): `three@^0.171`, `@react-three/fiber@^8.17`, `@react-three/drei@^9.117` (se necessário), `@react-three/postprocessing@^2.16`, dev `@types/three@^0.171`. `npm install` + build verde.

### C. Geometria pura (TDD vitest)

`webui/src/stage/brain3d/geometry.ts` — port das funções do canvas 2D: `insideBrain`, `inFissure`, `radiusInDir`, `gyri`, `buildBrainGeometry(n)` → `{positions: Float32Array, altPositions, edges: Uint16Array(pares), stemIdx, stemTip}`; determinístico via PRNG com seed (mulberry32) para testes estáveis.
`geometry.test.ts`: contagens (n nós + 7 stem), arestas válidas (índices < n, sem duplicatas), fissura vazia (nenhum ponto em |z|<0.055 && y>0.28), stem encadeado.

### D. Cena 3D

`webui/src/stage/brain3d/Brain3D.tsx`:
- `<Canvas>` com DPR cap 2, câmera fixa; grupo do cérebro com rotação Y contínua + pitch 0.14 + respiração (escala);
- **Pontos:** BufferGeometry com positions animadas por frame (lerp base⇄alt no thinking + jitter), PointsMaterial additive;
- **Arestas:** LineSegments atualizadas dos mesmos buffers, opacidade por estado/envelope;
- **Núcleo:** Sprite com textura radial (canvas), escala/intensidade por estado + envelope + flicker no thinking;
- **Pulsos sinápticos:** pool de pontos animados ao longo de arestas aleatórias (spawn rate por estado);
- **Chip:** grupo de meshes (base, die emissivo, pinos) no "chão", brilho por estado;
- **Raios:** 1-3 polylines jagged regeneradas a ~70ms entre stemTip e chip, intensidade por estado/envelope;
- **Ondas de voz:** anéis (RingGeometry) emitidos quando envelope alto, expandem e somem;
- **Bloom:** `<EffectComposer><Bloom ... /></EffectComposer>`;
- Estado vem de `useNox(s => s.state)` (baixa frequência); `level` lido em `useFrame` via `store.getState()` com suavização spring; muted esmaece (opacidade global).
- Parâmetros por modo idênticos ao TARGET do canvas (rot/jit/morph/spawn/edgeA/coreI/boltN/boltA).

`webui/src/stage/brain3d/index.tsx`: detecção WebGL (`canvas.getContext('webgl2'||'webgl')`) → `<Brain3D/>` ou fallback `<Brain/>` (2D).
`App.tsx`: troca o import para o novo índice.
